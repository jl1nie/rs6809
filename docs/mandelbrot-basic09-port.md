# 画像のBASIC09からCへの移植

`examples/mandel.c` は、指定された画像の `PROCEDURE mandel` に合わせた直接移植。
以前の固定小数点版は `benchmarks/mandel_fixed.c` として保存した。

| BASIC09の要素 | C版 |
|---|---|
| `X=-39 TO 39` / `Y=-12 TO 12` | 同じ両端を含むループ、79×25文字 |
| `CA=X*.0458` / `CB=Y*.08333` | 同じ定数の実数演算 |
| `A=CA` / `B=CB` | 初期値をz=cにする |
| `I=0 TO 15` | 最大16回更新 |
| T計算→B更新→A=T→発散判定 | 同じ順序 |
| `A*A+B*B>4.` | 更新後に4.0超で終了 |
| 発散しなかった点 | 空白 |
| `I>9`なら`I=I+7`、`CHR$(48+I)` | 同じ処理で0〜Fを表示 |

Cでは `double` を使用する。BASIC09のREALとすべての入力で同じ丸めになるという意味ではない。
この座標・反復条件では、元のBASIC09も実際に実行して比較し、**1,975文字すべての一致**を確認した。
C版は端末のページ送り待ちを一時解除し、表示後に元の設定へ戻す。

```sh
sh examples/mandelbrot.sh
```

手動実行：

```text
chd /dd/SOURCES
cc mandel
./mandel
```

元のBASIC09ソースも `/dd/SOURCES/mandel.b09` に収録する。
両方を実行して比較するには、ディスク構築後に：

```sh
python3 scripts/compare-basic09-port.py
```

## SDドライバの修正

浮動小数点ライブラリをリンクすると、参照キットのmc09sdドライバのLSN0誤判定が表面化した。
元の判定は24ビットのセクタ番号の各バイトを8ビットで加算しており、`$0004FC` などもゼロと誤判定する。
その結果、通常ファイルのデータをドライブのLSN0情報へコピーし、ディスクIDエラー（251）が発生した。
最適化前のエミュレータでも同じ症状を確認した。

`build-c-disk.py` は生成するCデモ用ディスク内のドライバだけ、加算2命令をOR2命令へ修正する。
アセンブラでCRCを再生成し、元のモジュールとサイズが同じ239バイトであること、
CRCを除く変更がこの2命令だけであることを検査して、OS9Boot内へ同じ位置・長さで置換する。
元の参照ソースと元のディスク、凍結した性能比較入力は変更しない。

テストでは生成したドライバの実際の命令列を取り出し、LSN上位バイト0・1・255について、
下位16ビットの全値を実行してゼロ判定を確認する。
実数版のコンパイル・リンク・描画・シェル復帰も回帰テストへ含めた。

## C移植版の速度ベンチマーク

2026-10-31、AMD Ryzen 9 9900X / WSL2、releaseビルドで計測。
BASIC09から移植した実数版（79×25文字、最大16反復）をNitrOS-9上のMicroware Cで
コンパイルし、この6809エミュレータで実行した。再検証でもBASIC09と1,975文字すべて一致した。

ウォームアップ1回後に7回実行し、描画バナー末尾から完了マーカー末尾を計測した。
起動・コンパイルは除外し、描画中のOS処理と文字出力は含む。出力はパイプで回収した。

| 指標 | 実測値 |
|---|---:|
| 描画時間の中央値 | 1.673355秒 |
| 最小〜最大 | 1.662165〜1.725248秒 |
| 描画の仮想CPUサイクル数 | 704,530,641 |
| 中央値でのエミュレーション速度 | 421.0 MHz相当 |
| 同じサイクル数の1 MHz換算時間 | 704.53秒（約11分45秒） |

全7回で描画・総サイクル数と出力ハッシュが一致した。
1 MHz換算は仮想サイクル数からの計算値であり、実機の実測時間ではない。
BASIC09自体との速度比はこの計測には含まない。
全試行と入力・実行ファイルのハッシュは [計測JSON](mandelbrot-c-benchmark.json) に保存した。

```sh
python3 scripts/compare-basic09-port.py
python3 scripts/benchmark-emulator.py --workload basic09 --runs 7 --output docs/mandelbrot-c-benchmark.json
```
